Pocket Dev Relay

スマホからPCのターミナルにアクセス。
Codex CLI や Claude Code を、どこからでも手のひらで操作できる開発コンソール。

GitHub セットアップ手順
$ npx pocket-dev-relay クリックでコピー
Features

主要な機能

モバイルファーストで設計された開発コンソール。必要な機能をコンパクトに提供します。

>_

リアルタイムターミナル

xterm.js ベースの本格的なターミナルをスマホのブラウザ上で操作。 Codex CLI、Claude Code、通常のシェルをワンタップで起動できます。

x5

複数セッション管理

最大5つのターミナルセッションを同時に実行。 タブUIで切り替えながら、並行して複数のタスクを進められます。

[ ]

ファイルブラウザ

ワークスペース内のファイルを一覧・閲覧・編集。 ターミナルと並行してコードの確認や簡単な修正が行えます。

PWA

PWA対応

ホーム画面に追加すればネイティブアプリのように利用可能。 Service Worker によるオフラインキャッシュにも対応しています。

L/D

テーマ切替

ライトモードとダークモードをワンタップで切り替え。 目の疲れを軽減しながら、好みの環境で開発できます。

///

トークン認証

環境変数でアクセストークンを設定し、不正アクセスを防止。 ローカルLAN上で安全に運用できます。

Setup

セットアップ

3つの方法から、プロジェクトに合ったやり方を選べます。

1

npx で即座に起動

インストール不要。コマンド一発ですぐに使えます。

# 最もシンプルな起動方法 $ npx pocket-dev-relay # ポートを指定して起動 $ npx pocket-dev-relay --port 3000
2

Docker で起動

コンテナ環境で隔離して実行したい場合に。

# Docker Compose で起動 $ docker compose up -d # または直接実行 $ docker run -p 3000:3000 \ -v $(pwd):/workspace \ pocket-dev-relay
3

ソースからビルド

カスタマイズしたい場合やコントリビュートする場合に。

# リポジトリのクローン $ git clone https://github.com/Y-Kanekoo/pocket-dev-relay.git $ cd pocket-dev-relay # 依存関係のインストールとビルド $ npm install $ npm run build # 起動 $ npm start
